# 🛍️ Fashion Marketplace — Community Design

ეს არის **Fashion Marketplace**-ის ვებგვერდი, რომელიც აწყობილია [Figma-ს დიზაინის](https://www.figma.com/design/eRIbFYL9ZJBluxw5Z8WV3t/Fashion-Marketplace--Community-) მიხედვით. დავალების მთავარი მიზანია დიზაინის HTML სტრუქტურაში ზუსტად გადატანა და თანამედროვე CSS ტექნიკების გამოყენება.

## 📌 პროექტის შესახებ

პროექტი წარმოადგენს მოდის და ონლაინ ვაჭრობის (Marketplace) სტილის სადემონსტრაციო გვერდს. მასში რეალიზებულია თანამედროვე UI/UX ელემენტები, პროდუქტების ბადე (Grid), კატეგორიების სექციები და ნავიგაცია — **მხოლოდ HTML5-ისა და CSS3-ის გამოყენებით (JavaScript-ის გარეშე)**.
